Givoice

음성으로 타이핑하세요.

Givoice는 음성을 텍스트로 변환해주는 보이스 입력 앱입니다. 네이티브 코드로 최소한의 기능만 구현했기에 가볍고 쾌적합니다. 본인이 사용하는 STT API 서비스를 연결하여 사용하세요.

1. 개발 동기

기존의 수많은 보이스앱 입력도구들이 있었지만 기능에 비해 메모리나 기능이 너무 무거운 단점이 있었고, OS에 기본적으로 있는 음성인식은 인식률이 2% 부족했습니다. 그래서 최소한의 기능으로 딱 필요한 말 소리를 타이핑으로 변경해주는 앱을 개발했습니다.

2. 다운로드

  • macOS 다운로드 (Apple Silicon __MACOS_ARM64_SIZE__ 또는 Intel __MACOS_X64_SIZE__ · DMG)
  • Microsoft Store에서 받기 (Windows 10/11 · x64)
  • Ubuntu 다운로드 (Ubuntu 24.04 이상 · amd64 · DEB)

macOS 버전 __MACOS_VERSION__ · 새 버전은 앱에서 알려 줍니다.

Microsoft Store에서 설치하면 자동으로 업데이트됩니다.

Windows 버전은 Microsoft Store 출시를 준비하고 있습니다.

Ubuntu 버전 __LINUX_VERSION__ · 다운로드한 DEB 파일을 열어 설치하세요. 새 버전이 나오면 앱이 알려 줍니다.

3. 사용 방법

외부 API 키가 필수입니다. OpenAI ↗ · ElevenLabs ↗ · Groq ↗

  1. 앱을 실행하고 메뉴바 또는 트레이의 설정...에서 ElevenLabs, OpenAI 또는 Groq API 키를 입력합니다.
  2. 마이크 접근을 허용합니다. macOS에서는 손쉬운 사용 권한도 허용합니다.
  3. 입력할 창에 커서를 놓고 오른쪽 Command(macOS), 오른쪽 Alt(Windows) 또는 Ctrl+Alt+Space(Ubuntu)를 누른 채 말합니다. 키를 놓으면 글이 입력됩니다.

설정에서 단축키, 인식 언어, 녹음 시간 제한과 붙여넣기 후 자동 전송 여부를 바꿀 수 있습니다.

Ubuntu: 단축키 / 권한 탭에서 전역 단축키를 등록하고 자동 붙여넣기를 허용하세요. 기본 요청 단축키는 Ctrl+Alt+Space입니다. 포털을 지원하지 않는 데스크톱에서는 녹음 버튼과 결과 복사를 사용하세요.
